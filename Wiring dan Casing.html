7Catatan Perakitan

  1. Ukur modul dulu. Cetak casing setelah modul fisik ada di tangan. Tiga penjual AD8232 bisa memberi tiga ukuran berbeda.
  2. Uji rangkaian di breadboard sebelum masuk box. Jangan solder ke PCB permanen sebelum semua sensor terbaca.
  3. Beri label tiap node (N1, N2, N3) di dalam dan luar box. Tanpa ini, log pengujian tidak bisa ditelusuri.
  4. Semua GND disatukan per unit. Jangan ada ground terpisah antara sensor dan ESP32.
  5. Cetak tutup terakhir, setelah bukaan terbukti pas.
  6. Urutan uji: sensor satu per satu → komunikasi satu node → tiga node → audio → casing.
